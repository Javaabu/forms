# Forms: notes for AI coding agents

`javaabu/forms` is a set of Laravel Blade components (`<x-forms::…>`) for forms and admin pages, with model binding, old input and validation errors. v2 renders for two frameworks, `onu` (Tailwind with `@javaabu/onu`'s classes, the default) and `bootstrap-6`, and has a React twin, `@javaabu/forms` (`Javaabu/react-forms`), with the same components and attributes.

## Layout

| Path | What |
| --- | --- |
| `src/Views/Components` | One class per component. Constructor parameters are the attributes; public methods and properties reach the view. `Component` is the base: framework, view resolution, ids, labels, icons, shared field options, assets. |
| `src/Frameworks` | `Framework` contract, `Onu` and `Bootstrap6` class maps (colours → classes), `Frameworks` registry |
| `src/Assets/Assets.php` | The only code that knows javaabu/manifest's registration API: the package's JS/CSS assets |
| `src/Support` | Traits for binding, old input, errors, media and formatting; `Settings` defaults; `Icons\Svg` |
| `resources/views/{onu,bootstrap-6}` | Per-framework views; `resources/views/common` is the fallback for both |
| `resources/onu/classes.php` | Generated by `scripts/onu-classes.mjs` from Onu's React components. Never edit by hand. |
| `resources/icons/icons.php` | Generated by `scripts/icons.mjs` from `lucide-static`. Never edit by hand. |
| `resources/js`, `resources/css` | Browser behaviours (TypeScript, no jQuery) and styles, built into `dist/` (committed) |
| `lang/{en,dv}` | Every user-facing string. Keys match `@javaabu/forms`' locales. |
| `docs`, `llms.txt` | Docusaurus pages and the index for AI assistants, both shipped in the package |
| `resources/boost` | Laravel Boost guideline and skill |
| `tests/Feature`, `tests/Unit`, `tests/TestSupport/views` | PHPUnit + BrowserKit tests and fixture views |

## Rules

- **Component names and attributes are a public API** used by every next-gen package. Don't rename or remove one; add new attributes with defaults that keep current output.
- **Both frameworks, always.** A markup change goes in `resources/views/onu` and `resources/views/bootstrap-6` (or `common` when the markup has no framework classes). `FrameworkSmokeTest` renders every fixture view with every framework.
- **Onu classes come from Onu.** Use `$frameworkClasses()->classes('slot.key')`; if a class you need is missing, extend `scripts/onu-classes.mjs` to capture it from Onu's own component and run `pnpm onu-classes`. Don't type Onu class strings into views.
- **Parity with React.** New components or attributes must match `@javaabu/forms` (camelCase there). Update `docs/parity.md`, and open a `cross-package` issue in `Javaabu/react-forms` when they differ.
- **Shared field options** (`form-group-class`, `thaana`, `auto-resize`, `decimals`) are read from the attribute bag in `Component::withAttributes()`. Views read them through methods (`$groupClass()`, `$thaanaAttributes()`, …) because Blade captures properties before `withAttributes()` runs.
- **No hard-coded text.** Strings go in `lang/en/strings.php` and `lang/dv/strings.php` (real Dhivehi; list uncertain lines in `docs/advanced-usage/translations-and-rtl.md`), using the same key as `@javaabu/forms` when one exists.
- **RTL:** logical utilities only (`ms-`, `pe-`, `start-`, `text-start`); never `left`/`right`.
- **Assets:** a component declares what it needs by overriding `assets()` (names from `Assets`). Don't push `<script>` tags from views, except third-party scripts that need config (Google Maps, TinyMCE) through `forms::partials.assets`.
- PHP follows Javaabu's guidelines (`vendor/javaabu/boost-javaabu-guidelines`): Pint, `#[Test]` and `it_…` test names, snake_case variables. Component constructor parameters stay camelCase, because Blade maps kebab-case attributes to them.
- Every change needs tests (Thaana text in user-facing cases), docs (and `llms.txt` for new pages), and a `CHANGELOG.md` line.
- Work happens on `next-gen` until v2 is merged; never commit to `main`.

## Commands

```bash
composer install && pnpm install
composer test            # PHPUnit
composer lint            # Pint (composer format to fix)
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test
pnpm build               # dist/: JS, CSS, Vite manifest
pnpm onu-classes         # regenerate resources/onu/classes.php after upgrading @javaabu/onu
pnpm icons               # regenerate resources/icons/icons.php
pnpm check               # CI: Onu classes match the installed @javaabu/onu
```
